# Remaining preserving local tests: training-only start policy

2026-10-18. **Preparation only: no independent labels or DFT have been
generated by this helper, and the forecast panel is not yet frozen.**
The author-approved [blueprint](../../../../docs/HFO2_PAPER_BLUEPRINT_2026-10-17.md)
requires one bounded ten-start training trial, followed by separately frozen
models, applicability domains and a new definition for the remaining P8
tests. This file specifies the start-selection ingredient, not a production
authorization or a completed prediction protocol.

The eight Q pairs remain the original nonzero points of
`{-0.05,0,+0.05}^2` in Angstrom, in original Manhattan-distance/lexical
order. No additional test point or training replacement is introduced.
T8 remain seen. The original E185/E188 forecasts and E254 two-dimensional
refusal remain unchanged and must not be reclassified as passing against
the revised target.

After complete native audit of all ten E260 outcomes, eligible parents are
only those satisfying **both** the original0.03eV/A full released-gradient
norm and1e-4eV/A zeta-gradient tests. Their stability is still unchecked.
For each independent Q, sort these parents by exact integer half-grid
squared Q distance, then original E260 candidate ID. Energy is not a
selection feature; the two initial signs do not automatically define two
branches. Set the two Q coordinates to the target while keeping the
parent's other components. Select the first start passing the unchanged
geometry guard. If none does, record refusal, without repair or a new start.

Every independent target receives at most **one** frozen start, not one
start per sign. Independent outcomes never supply continuation parents.
The later execution must retain the E260 optimizer/positive numerical seed,
dual stopping tests,0.5A total internal-coordinate radius about zero,
1.6A minimum distance and12 fresh attempted-SCF cap per point. The remaining
P8 budget is96 attempts maximum, separate from training; no rollover/retry.
ABACUS/PBE/100Ry/full10auDZP/original KPT/binary/six assets/P0/E0 stay exact.
No physical+0.005 geometry or labels are needed to select these starts.

The resulting observable is an **algorithm-defined single-start gradient
candidate**, when obtained. It is not a guaranteed conditional minimum,
unique branch or TS. A change of target/start definition must be explicit
in the final preregistration and scoring; it cannot repair the original
forecast retrospectively. Numerical errors, valid coverage and preparation
cost all remain required. An unidentifiable or unvalidated model must retain
its abstention rather than interpolate through the failed training center.

`target_policy.py` has no calculator, scheduler or file I/O. Its caller must
first verify and externally pin the complete native cohort report, and
later freeze the actual models, strong controls, predictions and test
configurations **before** any of these eight labels. The four synthetic
checks verify target coverage, deterministic selection, both gradient
tests and explicit geometry refusal; they are not material validation.
