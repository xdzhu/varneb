# E112: complete-panel artifact freezing, not a material forecast

The new `vcneb.forecast_freeze` interface snapshots already computed model
artifacts, a comparison contract, a registration and the same declared
visible-input set for every model. All registered cases, baselines and
abstentions are retained. A loader verifies the whole byte graph against an
**externally retained manifest SHA256** before returning the existing
`FrozenChannelForecast` records. Rewriting a local receipt cannot replace
that external trust anchor. No source/model code is executed by the loader.

This is a missing software integration boundary between the existing
response kernels and scorer. It does not implement a new predictive theory,
select a material basis/bottleneck, certify DFT, prove chronological blinding
or authorize a holdout. Receipts leave all those material/authorization
claims false. A smaller caller-declared panel does not satisfy the actual
HfO₂ v1/v2 protocol. See [API contract](../../../../docs/FORECAST_PANEL_FREEZE.md).
