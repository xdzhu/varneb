## What is checked

The fixed36Djoint length chart has the original rank2retained plane and a
rank34released complement. For each of40nearest axial edges,

`DeltaE - Wq = Wr + R`,

where Wq and Wr are signed endpoint-gradient trapezoids, and R is the full
energy-minus-trapezoid discrepancy. The existing `vcneb.path_work` supplies
the contraction. Direct Q/R formulas and a separate full40D contraction
check the same work, retaining atomic/open-cell/prescribed-control pieces.
The fixed control's work is zero; no ASR or atom/periodic rematching occurs.

The endpoint inequality

`abs(Wr) <= (norm(gr_left)+norm(gr_right))*norm(Delta_r)/2`

bounds only that endpoint trapezoid. It is **not** an energy, interpolation
or barrier-error bound. The test suite includes E(r)=3r^2-2r^3 between0and1:
both endpoint derivatives vanish but the energy changes by1. Closed energy
loops telescope exactly, while endpoint-gradient quadrature can circulate.
That circulation does not establish nonconservative DFT forces, and a large
neighboring displacement alone does not establish a branch jump.
