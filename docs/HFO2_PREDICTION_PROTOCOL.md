版本1，2026-10-08。本协议在G2材料计算/标签出现之前固定；第一版Git提交
作为事前记录。修改须另留版本、原因和已见数据，不能覆盖旧记录后称原始预测。
执行关口/13条新链上限仍见[主方案](VARNEB_JCTC_HFO2_RESEARCH_PLAN.md)。

## 1. 科学目标和覆盖

检验同一PO+初态下，机械约束是否使均匀翻转与M/T退相变发生不同的势垒响应，
以及模式—应变模型是否提供优于简单插值/势阱响应的未见条件预测。
“选择性增加”与“退相变绝对势垒不降低”分开；不是寿命、矫顽场或所有路径
的全局最低垒。当前两翻转种子由登记母相操作定义，不自动对应不可约表示、
文献type I–IV、互不相通的拓扑或独立MEP。优化为同一路径也必须报告。

Qi2025讨论的穿越Hf平面第三类不在当前四候选集中。完成当前矩阵后，对这类
遗漏机制是否破坏结论作覆盖审查；未经说明不追加新链，也不以候选集最低值
宣称全局最优。某边界下端点消失，记录相/分支失去亚稳性，不伪造势垒标签。

Behara2022还给出同取向七对变体中的Pbcn中间态路径，且固定完整O胞会把
其中间态变成T。当前T-pattern符号标签不是该分类的认证；覆盖审查同时检查
这类中间态/变体遗漏，不以两个符号就宣称全部翻转。仍不自动追加生产链。

## 2. 数据划分、锁定时点与选择规则

- **训练/筛选**：G2同一T基底取向、相同夹持定义的ε=0及+0.01；G1自由胞
  只用于种子/表示审计，不冒充同一夹持应变分支的训练点。
- **路径holdout**：ε=+0.005，最多两条完整路径。它是范围内未见条件，
  不是外推。生产结果、完整标签和轨迹不得参与选模、参数拟合或分支修正。
- **选两条边**：仅用G2训练数据，分别选择最低翻转候选和最低M/T退相变候选。
  两端训练条件若最低候选不同，优先保留在ε=0最低者，并报告交换/未分辨；
  不看holdout后换边。如最低值的误差区间重叠，按已登记名字排序确定代表，
  报告选择不确定而非宣布唯一最低通道。
- 两个holdout只能验证所选边；未算其他边时，不能认证该条件全网络最低值
  或通道交叉。已有0/+1%完整四边网络仍分别做覆盖审计。
- **局部面holdout**：每面8个独立DFT点，在≤81点的建模采样集之外。坐标、
  分支起点、留出位置、选择算法和误差阈值先写入带哈希manifest再算。
  面内加点不吞并已公布holdout；新增测试集另登记，不抹去首轮失败。
- 预测文件先冻结：代码/数据哈希、可动子空间、基矢与归一化、训练点、
  条件、目标边、预测值/界、局部分支和适用域。先锁定，再读取路径holdout。
  模型如果需要holdout端点E/F/stress，明确这是可见的输入特征及实际成本，
  不称零DFT预测；所有使用该特征的对照获得相同输入。

## 3. 必须报告的对照，不只展示最好模型

| 模型/对照 | 含义 | 防止的误解 |
|---|---|---|
| B0 直接势垒插值 | B(+0.005)=(B(0)+B(+0.01))/2；不看模式 | 中点holdout简单插值也能预测，不能把一致误称复杂方法优势 |
| B1 势阱响应两种零拟合基线 | 固定瓶颈绝对能量响应为零：ΔB=-ΔE_IS；或瓶颈跟随FS：ΔB=ΔE_FS-ΔE_IS | 用端点能差/共同初态移动就可解释的变化，不需要新机制 |
| B2 冻结少数模式 | 同一规范的模式/应变坐标，不释放被省略自由度 | 模式投影占比不是能量贡献，冻结面不等于条件面 |
| B3 仅释放原子 | 同一可见训练点；晶胞自由度不参与消元 | 原子优化是否已足以解释瓶颈响应 |
| B4 联合原子—晶胞释放 | 显式同边界子空间，稳定H_rr的局部二阶响应 | Schur公式本身不是新理论，实际改善须独立检验 |
| B5 稳定性/分支感知 | 训练阶段失稳时增维或分支；不以伪逆隐藏负方向 | 增维是不是必要，失败区域是否确实被识别 |

所有基线都保留，不在结果出现后只选一个弱基线作比较。某模型缺少必要数据
或适用条件则标不适用及原因，不能用“未算”支持其效果差。B2–B5的局部基矢
仅由训练瓶颈选取，简并子空间整体比较；T-triplet不得被强制当所有通道的完整面。
驻定性不够时不能直接将应力偏导认作鞍点分支包络导数。失稳而拒绝预测是边界
诊断，不作为成功数值预测；拒绝率、预测覆盖率和有效点误差同时报告。

## 4. 数值判据与结果分类

每条边记录B、ΔE、梯度、离散采样/SCF误差界、相身份、机械反力/开放牵引、
真实调用数与核时。普通NEB门槛仍0.10eV/Å，不换算为势垒误差或TS认证。
端点与真正瓶颈的响应分别报出，不只报相减后的曲线。

H1严格主判据事前设**退相变非劣界δ=0eV/f.u.**：要求翻转下降的区间上界<0，
且已考察最低退相变变化的区间下界≥0。若区间含0或Bd略降，不称此强结论
成立；相对S增大可单独报告。这个严格分析标准不是改变DFT/NEB的精度门槛。
不事后改一个容许损失量使结论通过。未来如提出有物理依据的非零δ，是独立
次级分析，另行登记理由和观察时点，不能覆盖主判据。

预测比较使用meV/f.u.的逐边误差及最大绝对误差，报原始误差、相对于实际
参考误差区间的未分辨部分；不把确定性界当高斯标准差。通道排序只在差异
超过界时检验。对于每个holdout，若B5相对B0/B1的改善不足以排除数值误差，
不能声称定量优势。若B0已经同样准确，按实证承认模式模型主要用于解释，
而非预测精度突破。两个路径holdout只构成该受限材料/机械条件的证据，
不作跨材料泛化的统计保证。局部面8点结果另报，不能与路径检验混淆。

独立点失败时记录首轮预测，再作训练/修正；修正后的拟合不是原预测通过。
形变分支不连续、额外负方向或端点消失时记录明确失败类别；不调cutoff、
赝势、轨道或SCF参数，不把分支跳变平滑为虚假的单一面。

## 5. 成本、验收与下一步

预测准确性、机制辨识、优化加速是三个不同结果。加速必须同种子、同物理
契约、同阈值和同最终通道；计完整链评估、真实SCF、总核时和准备成本，
不能以更短步数但换路径作为加速证明。局部条件弛豫每点可能多次SCF。

G1仍先完成当前四候选，不因本协议新增作业。G2关口后才执行夹持矩阵，
G3按已声明两瓶颈/两面上限进行。当前只有T固定胞原子局部8点预测，
没有G2材料结果/上述holdout结果，不宣称完整模式—应变预测已验证。

验收不要求H1产生有利窗口，但要求一个真实同边界竞争响应结论及其解析，
并检验H2是否提供相对明确基线的可量化优势。若仅复现模式耦合和NEB、或
模型无额外预测优势，不将其包装为JCTC新方法。CPC稿件和既有数据继续保留。
