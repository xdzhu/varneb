# 双层 hBN：固定胞与面内变胞 VARNEB 的验证协议

**状态：研究设计，尚无本项目的双层 hBN DFT 结果。** 本案例的首要作用是
检验 VARNEB 在二维体系中退化为固定胞 NEB，以及在只开放面内应变时
路径和势垒是否发生可复现的变化；不能在计算前断言面内变胞必然降低势垒。
它是 BTO/GaN 模式与路径分析闭环之后的独立扩展，不替代正在审计的
材料结果。

## 科学对象与坐标

选取**相同层取向**下、由相对滑移连接的两个对称相关极性堆垛。
实验报道的双层 hBN 滑移铁电性涉及亚稳的非中心对称平行堆垛，
不能把任意最低能中心对称堆垛直接称为铁电端点
（[Vizner Stern 等，Science 2021](https://doi.org/10.1126/science.abe8177)）。
建立端点时保存每个原子的层归属、元素顺序、晶胞、分数坐标、滑移矢量及
原始结构来源；两个端点须严格同原子数、同势函数与同二维周期胞约定。

以两层各自的 B/N 质心定义相对平移 `u=(u_a,u_b)`，对共同平移取商，
并按面内晶格矢量取模。沿路径另记录层间距 `d`、相对层内畸变、
面内应变及重构残差。`u_a,u_b` 是**层滑移序参量**，不自动等于单条
声子本征矢；可独立投影到 Γ 层间剪切与呼吸模。若只求所选四原子
二维原胞的 Γ 模，声子有限位移使用 `1×1×1` 即可；电子 k 网格需
单独收敛。需要非 Γ 模、畴壁或畴成核时才引入更大的面内胞。

## 两种边界条件必须分开报告

1. **固定胞：** 每个 image 使用完全相同的 `a,b,c`，`cell_mask=0`；
   只允许原子自由度和选定的层间距弛豫。这是普通 NEB 退化回归。
2. **面内变胞：** 仍固定真空方向 `c` 和所有 `xz/yz/zx/zy/zz` 形变；
   只开放经测试的 `xx,yy,xy` 面内对称应变及原子自由度。
   不能把现有九分量 `cell_mask` 的任意 `xy/yx` 组合未经能量—梯度
   有限差分检验就视为对称二维应变实现；还需排除纯刚体转动。
   先做解析 toy 和一像 DFT 应力—能量导数核验，再提交整条路径。

两套比较必须使用同一泛函、色散方案、赝势/基组、k 网格、真空高度、
偶极处理、端点物理态、image 数与优化停止规则。保持相同 `c` 是为了
让有效三维应力的尺度可比；面内零应力不能直接解释成三维静水压
或未注明厚度的二维模量。当前 VARNEB 的 `cell_mask` 已支持固定胞
退化，但**尚无双层 hBN 面内剪切变胞的材料级验证**，故第二方案
目前是待实现/验证的协议，而非宣称已可生产。

## 能量面与路径的两层验证

- 先在滑移环面上做少量独立静态点：`E_frozen(u_a,u_b)` 固定层间距
  与层内结构；`E_cond(u_a,u_b)` 保持滑移约束，仅弛豫层间距及
  其余允许的原子自由度。若再允许面内应变，那是**第三张条件面**，
  不得把不同边界条件的点混作同一 contour。
- 通过自适应加点与留出点误差检查后才插值等高线；标出实际 DFT 点、
  周期边界、端点及经过审计的 NEB image。路径点的真实能量与在
  `(u_a,u_b)` 上插值的面值分别保存，不从投影图直接读势垒。
- 固定胞路径先对照相同设置的 ASE NEB；面内变胞路径再与其比较
  正反向势垒、鞍点堆垛、`d(s)`、应变及路径形状。若两者差异接近
  数值误差，只报告不可分辨，不强行讲“变胞效应”。

双层堆垛能对色散处理敏感，已有第一性原理广义堆垛层错能研究
专门比较了多种色散方案
（[Zhou 等，PRB 2015](https://doi.org/10.1103/PhysRevB.92.155438)）。
因此提交整条链之前须对代表性端点、候选峰及至少一个中间滑移点
做 k 网格、真空高度、电子收敛、层间距和色散方案的差值收敛；
门槛要相对预期的 meV 级势垒设定，不能只凭默认 NEB
`0.10 eV/Å` 力阈值宣称能垒精度。所有能量同时写明
`eV/所用双层原胞` 与必要时的 `meV/面积`，不偷换分母。

## 模式和极化：分别建证据链

在选定的高对称/端点堆垛处，计算 Γ 点力常数，分离整体平移、
相对层剪切、层间呼吸及内部振动，记录质量加权归一化、简并模
旋转/gauge、模式幅度与路径残差。固定胞 Γ 的 `1×1×1` 与电子 k
网格是不同概念；该基不能描述畴壁或有限波矢不稳定性。

`energy/forces/stress` 不含极化可观测量。若要使用“滑移铁电”
或论证极化翻转，必须另算电子极化/层间偶极并审计相位分支、
真空和偶极修正；比较两端的符号与路径演化，分开电子重排和
离子贡献。实验和理论均提示电子贡献不可忽略
（[Vizner Stern 等，Science 2021](https://doi.org/10.1126/science.abe8177)；
[Jiang 等，PRB 2022](https://doi.org/10.1103/PhysRevB.106.054104)）。
均匀小胞滑移势垒不能外推为器件畴壁成核垒或矫顽场。

## 提交前及完成后的硬闸门

| 阶段 | 必须保留的证据 |
| --- | --- |
| 结构 | 两个堆垛的来源、同原子顺序/化学式、层标记、相对滑移、真空与近邻距离；端点各自独立弛豫及同协议静态基准。 |
| 计算契约 | 完整有效输入、版本、赝势/基组哈希、色散/偶极设置、k 网格、固定/开放应变掩码、输出单位；不能在 image 间暗中改变。 |
| 数值预检 | 至少三处代表性堆垛的能量差收敛；面内应变实现的能量—应力有限差分；固定胞退化回归。 |
| 路径 | 每像 SCF 成功、原始能量/力/应力、端点复用、最新完整链、实际投影力与正反向能垒；不因单步受力回弹停算。 |
| 分析 | 原始 PES 点与留出误差、实际路径覆盖、模式幅度/残差、固定/面内变胞差值及误差条；极化主张另有电子证据。 |
