# Provenance

This report was prepared on 2026-09-12 from primary or project-maintained
sources accessed through web search and source pages. The main evidence sources
were the Qian VC-NEB paper and USPEX manual, the Sheppard G-SSNEB paper and
TSASE documentation, the Ghasemi FD-NEB paper and repository, the current ASE,
ABINIT, VASP, QuantumATK, SIESTA/FLOS, and ABACUS documentation, and selected
HfO2/application papers listed in the report.

The table is representative rather than an exhaustive bibliometric census. Claims
about current support are limited to what the linked documentation states. In
particular, “no VCNEB feature found” for a project means the surveyed current
documentation did not document it; it is not a proof that no private branch or
unpublished script exists.
